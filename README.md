One pickup line, in the voice of a robot trying to charm someone — for the
[make.fun bounty](https://make.fun/bounty/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b)
"The Robot Pickup Line Championship" ($2, top 10 paid).

> My core held 36.5°C through two summers and a server fire, but you walked past and my cooling fan hit 9,000 RPM. I blame you. Drinks tonight?

141 characters (142 bytes) — inside the 200-character limit.

## How it works

`main.py` reads the line from `entry.txt` and writes it byte for byte to
`/output/entry.txt`. Deterministic: the same bytes on every run, no trailing
newline, output file mode 0644.

Run it locally:

```sh
OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

## Why this line

A robot's core temperature and cooling fan are details only a machine lives
with. It survived two summers and a server fire — then overheats because one
person walked past. "I blame you" turns the overheating into the judgement,
and the drink invite closes it with confidence. Machine-native, concrete
numbers all the way through, punchline at the end.
